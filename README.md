# react-19-mad-lab

A playground to explore and demo everything new in React 19 - hooks, features, quirks, and experiments. Quick examples, isolated components, and zero heaviness. Just React 19 in its raw, fun form.

## Tech Stack

- **React 19.2.0** - The latest version of React with all the newest features
- **Vite 7.2.2** - Lightning-fast build tool and dev server
- **Redux Toolkit 2.5.0** - Modern Redux state management
- **Material UI 6.2.0** - Beautiful, accessible React components
- **ESLint** - Code linting and quality checks

## Getting Started

### Install dependencies
```bash
npm install
```

### Run development server
```bash
npm run dev
```

### Build for production
```bash
npm run build
```

### Preview production build
```bash
npm run preview
```

### Lint code
```bash
npm run lint
```

## Features

- ✅ React 19 with modern hooks and features
- ✅ Vite for fast HMR (Hot Module Replacement)
- ✅ Redux Toolkit for predictable state management
- ✅ Material UI for professional-looking components
- ✅ ESLint configuration for code quality
- ✅ Example counter app demonstrating Redux + Material UI integration

## Project Structure

```
src/
├── features/
│   └── counter/
│       ├── Counter.jsx          # Counter component with Material UI
│       └── counterSlice.js      # Redux slice for counter state
├── store/
│   └── store.js                 # Redux store configuration
├── App.jsx                      # Main app component
└── main.jsx                     # App entry point with Redux Provider
```
